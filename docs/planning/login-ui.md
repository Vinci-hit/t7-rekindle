# 登录 UI 与暖白面板规范

本规范补充现有启动器 UI，以 2026-10-10 确认的登录设计为基准。实现使用 WPF/net48 和项目已有的 WebView2 SDK；认证、会话保存、心跳与推送协议保持不变。

## 范围与层级

- 标题栏、账号胶囊、账号菜单、QQ 登录承载区和网页组件缺失提示。
- 其他页面沿用原有设计；暖白配方可用于后续设计，不意味着立即替换所有旧面板。
- 正式界面使用账号服务返回的身份和 QQ 实际授权页，不包含演示头像、昵称、号码或截图二维码。
- 下表尺寸为 DIP，由 WPF 处理 DPI；字体沿用 Microsoft YaHei UI 字体栈。深色及高对比度使用同名语义资源覆盖，不改变结构和状态语义。

## 暖白表面

| 用途 | 表面 | 边界与布局 |
| --- | --- | --- |
| 基础色与文字 | 基色 `#FCFBF7`；主文字 `#203D49`；常规墨蓝 `#294C5C`；辅助文字 `#64757D` | 表面不透明，不添加纹理，不通过整个面板的透明度淡化文字 |
| 主内容区标题栏 | 向下渐变 `#FDFDFA → #F6F7F5` | 高 62；右留白 20；底边 `#D6DCD9`、35% 不透明度；保留左侧品牌区域 |
| 账号菜单 | 向下渐变 `#FFFEFB → #F8F7F1` | 宽 280、高至少 58；内边距 12；圆角 10；1 DIP `#D7DCD6`；白色顶部高光 |
| QQ 原页 | `#FFFFFF` | 636×378；无宿主标题、边框、圆角或底部操作栏 |
| 缺少网页组件 | 145° 渐变 `#FFFEFB → #F9F8F2` | 基础尺度 636×378；内边距上 48、左右 24、下 36；小工作区可滚动，不裁掉操作 |

菜单以两层柔影区分浮层：近影深度 3、模糊 7、不透明度 10%；外影深度 15、模糊 30、不透明度 20%；颜色均为 `#182527`。弹窗使用原生窗口层级，登录期间主窗口遮罩为 `#1B2628`、40% 不透明度。阴影栅格化由 WPF/Windows 完成，不把静态切图作为控件。

## 账号胶囊

### 业务状态

| 状态 | 显示 | 点击 |
| --- | --- | --- |
| 未登录 | 仅「未登录」，无头像、状态点或箭头 | 打开一次 QQ 登录窗口 |
| 在线 | 深绿点、头像、昵称、下拉箭头 | 展开/收起账号菜单 |
| 离线 | 深灰点、头像、昵称、下拉箭头 | 同样允许打开菜单和退出 |

身份以账号服务验证成功为准；扫码本身不等于启动器登录成功。在线表示已有连接且心跳正常；推送重连不清除身份，心跳失败或连接被接管显示离线。QQ 客户端状态与此无关。退出清理本地账号会话，连接掉线保留身份；这两种操作均不覆盖玩家名称或游戏目录。

### 等待服务端响应

- 登录验证、恢复登录、上线和重新上线请求尚未完成时，胶囊显示 14×14 加载圆环，以 1 秒一圈匀速旋转，沿用墨蓝前景色。
- 未登录时显示「圆环 + 登录中」，间距 6；已确认身份时保留头像、昵称和状态点，以圆环替换下拉箭头。尺寸与业务状态配色保持不变。
- 提示和可访问名称说明当前阶段；等待期间不重复发起登录，已有身份仍可打开菜单并退出。
- 成功、失败、取消或窗口隐藏时停止动画；过期响应不影响新请求的加载状态。等待扫码与后台心跳、推送连接不显示此动画。
- 遵循系统减少动态效果设置：关闭动画时保留静态圆环和阶段提示，不只依靠运动表达加载状态。

### 尺寸和内容

- 高度固定 36；未登录宽 96，已登录宽 144–224，按下不移动、不缩放。
- 未登录内边距左右 14、上下 5；已登录左右 10、上下 5；边框 1、圆角 18。
- 已登录固定顺序：8×8 状态点 → 24×24 头像 → 昵称 → 14×14 下拉箭头；间距 8。
- 头像圆角 6、底色 `#E8E9E3`；失败显示 Lucide `user-round`，不改变身份和连接状态。
- 胶囊文字 13 / Medium，默认 `#315266`，强调 `#25465B`。昵称单行省略，完整内容保留在提示和可访问名称中。
- 展开时箭头转 180°。真实键盘焦点显示 2 DIP 间隔色 `#FFFEFA` 与 2 DIP 外环 `#638296`。状态切换不依赖动画，尊重减少动态效果。

### 状态配方

以下为 HSL 设计值转换后的 sRGB 值，渐变均向下：

| 状态 | 默认渐变；边色 | 悬停渐变；边色 | 按下渐变 | 展开渐变；边色 |
| --- | --- | --- | --- | --- |
| 未登录 | `#FFFEF9 → #F0EBDF`；`#C7BDA4` | `#FFFDF4 → #ECE4D3`；`#AB9A76` | `#E9E0CE → #F3EDDF` | `#F1E9D7 → #E9DEC8`；`#A18D66` |
| 在线 | `#F5FAF7 → #E1EFE7`；`#B3CCBE` | `#EEF6F2 → #D7EADF`；`#8CB59E` | `#CDE5D7 → #E1EFE7` | `#E1EFE7 → #CDE5D7`；`#7DB093` |
| 离线 | `#F9FAFB → #EEF0F2`；`#B9C3CA` | `#F3F5F6 → #E2E6E9`；`#96A5B0` | `#D9DFE2 → #EBEEF0` | `#E8EBED → #D6DCE0`；`#8B9BA7` |

按下用对应展开边色，焦点用对应悬停边色。在线圆点 `#3B7253`，离线圆点 `#5C6E7A`；稳定状态不闪烁。默认下影 1/2/10%，悬停 2/4/14%（深度/模糊/不透明度）；按下改为内边反馈。

## 单行账号菜单

- 同一行：32×32 QQ 头像 → QQ 昵称（完整 QQ 号码）→ 32×32 退出图标；头像圆角 8。
- 昵称 14 / Medium，号码 12、等宽数字；仅昵称允许省略，号码与退出点击区不收缩。
- 菜单右边缘对齐实际胶囊右边缘，菜单表面位于胶囊下方 8 DIP；定位计算不把阴影留白当作控件宽度。
- 没有标题、单独状态行、分隔线、文字退出按钮或切换账号入口。原有重新上线命令保留在业务层，不加入该单行菜单。
- 外部点击收起；Escape 收起并回焦；退出不二次确认，恢复「未登录」并回焦。
- 退出使用 `log-out`，提示和可访问名称为「退出登录」。悬停底色 `#F7EBE6`、边色 `#E9D3CA`、图标 `#9B5146`；按下底色 `#EDD8CF`。

## QQ 原页与组件提示

### 正常页面

原页面自身处理二维码、快捷头像授权、密码登录与页面底部链接，宿主不重绘。只在右上角叠加重载和取消：距顶部/右侧各 10，间距 4，点击区 32×32、圆角 7、图标 17、描边 1.8。

重载刷新整个当前页面；取消/Escape 关闭本次登录，不注销已有身份。重复点击不创建第二个登录窗口；关闭后或过期导航的回调不恢复窗口或身份。

承载控件使用现有 SDK 的 `WebView2CompositionControl`，让 WPF 图标位于网页上方，避免 HWND airspace 遮挡。参见 [Microsoft 的 WPF WebView2 说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/platforms/wpf)。

### 组件不可用

先检测 Runtime，再创建浏览器；提示完全由原生 WPF 绘制：

> 暂时无法打开 QQ 登录页
>
> 未检测到可用的网页组件。请安装适用组件后，点击「重新检测」。

- 「前往下载」在系统浏览器打开 [Microsoft Edge WebView2 Runtime 下载页](https://developer.microsoft.com/microsoft-edge/webview2/)，不改为外部 QQ 授权。
- 「重新检测」再次检测，可用时创建网页控件；右上角只有「取消登录」。
- 辅助文字：「组件下载页将在系统浏览器中打开。」
- 图标底座 48×48、圆角 11，渐变 `#FFFDF5 → #EEE4CB`、边色 `#D3C39E`；内部 `app-window` 26、描边 1.6、颜色 `#957946`。
- 标题 21 / Medium；正文 14、行高 24.5、最大宽 370；帮助 12。按钮高 36、最小宽 116、圆角 6、左右内边距 16、图标 16。
- 主按钮 `#466777 → #2C4D5D`、边色 `#95845C`、白字；悬停 `#507483 → #315566`，按下 `#2D4D5A → #426473`。
- 次按钮 `#FFFEFD → #F0F2EF`、边色 `#C9D5D8`、墨蓝文字；悬停 `#FFFEFD → #E8EEED`，按下 `#E2E9E7 → #F1F3EF`。

网页网络故障和其他初始化失败使用「重新加载」反馈，不提示安装 Runtime。账号服务拒绝登录或未配置服务时，错误通过现有 Toast 展示，并保留账号入口的详细提示。

## 实现和验证入口

| 入口 | 职责 |
| --- | --- |
| `Resources/LoginPalette.xaml`、`LoginControls.xaml`、`AccountCapsule.xaml` | 配色、矢量图标、控件与五交互态；深色/高对比度覆盖在现有主题字典 |
| `Views/AccountPanel.xaml` | 胶囊、头像回退、菜单布局、回焦与退出 |
| `Views/QqLoginDialog.xaml` | 原生提示与两个叠加图标；检测、创建、重载、取消及回调生命周期 |
| `ViewModels/AccountViewModel.cs` | 身份/在线/登录窗口/服务端等待状态，不通过显示文案反推状态 |
| `tests/managed/AccountUiTests.cs`、`QqLoginUiTests.cs` | 状态语义、重入、长昵称、头像回退、菜单定位、故障分类及 DPI 布局 |
| `tests/managed/AccountLoadingTests.cs` | 响应等待、取消与过期响应、加载动画启停、减少动态效果和 DPI 布局 |
| `tests/managed/LoginNativeUiTests.cs` | 在实际 WebView2 中加载本地夹具，检查叠加按钮命中、整页重载、Escape、菜单焦点和离线退出 |
| `tests/python/test_login_ui.py` | 单行结构、无重复宿主标题、原生提示与独立资源契约 |

在仓库根目录运行：

```powershell
python scripts/build.py --project managed
python -m pytest tests/python/test_login_ui.py tests/python/test_ui_v11.py tests/python/test_ui_contract.py -q
& .\artifacts\bin\T7R.ManagedHarness\x64\Release\net48\T7R.ManagedHarness.exe --account-tests artifacts/login-ui
& .\artifacts\bin\T7R.ManagedHarness\x64\Release\net48\T7R.ManagedHarness.exe --render-ui artifacts/login-ui-full
& .\artifacts\bin\T7R.ManagedHarness\x64\Release\net48\T7R.ManagedHarness.exe --login-ui-native artifacts/login-ui
```

渲染入口覆盖 100%、125%、150%、175%、200% 和小工作区；完整 UI 回归额外覆盖深色、高对比度和 WPF 绑定警告。真实 QQ 扫码/密码授权、不同提供方页面下的遮挡、Runtime 安装后恢复及跨屏混合 DPI，需用实际系统与账号继续验收；离线夹具不替代这部分结果。
