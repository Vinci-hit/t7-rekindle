# 战斗手感

手感取决于四件事：本地操作无延迟、命中反馈与画面同步、对手动作可信、判定公平。本项目沿用成熟动作游戏的做法，并受限于原版客户端的结构。

## 原则与做法

| 原则 | 业界做法 | 本项目 |
| --- | --- | --- |
| 本地操作零延迟 | 本地角色由客户端立即响应，服务端只校验 | 原版客户端自行移动，服务端校验速度预算，不接管 |
| 命中与画面同步 | 伤害、音效、特效绑定到动画的有效帧，而不是请求到达的时刻 | 玩家命中取自原生刀刃接触；怪物伤害延后 `PRESENTATION_DELAY_MS`，与客户端对远端动作的回放延迟一致 |
| 防止连击锁死 | 受击硬直之后给予短暂的抗打断（韧性／霸体） | 怪物硬直结束后 800 ms 内不再进入新的硬直 |
| 攻击有节奏 | 同一目标同时只有少数敌人出手（攻击令牌），其余绕行 | 同一目标的怪物起手至少间隔 700 ms，其余沿目标侧移 |
| 不卡死 | 卡住检测、绕行与放弃目标 | 见 [PVE](../game-server/docs/pve.md) 的怪物行为 |
| 判定公平 | 延迟补偿：按事件发生时的画面回溯，而不是处理时的状态 | 服务端保存姿态历史，按接触发生时间回溯裁决 |

## 呈现延迟

客户端把远端演员（其他玩家与怪物）的动作按至少 100 ms 的延迟回放，以便插值。服务端若在动作开始后立即按原时刻结算怪物伤害，玩家会在刀光出现之前就受伤。常量 `PRESENTATION_DELAY_MS`（Rust，`limits.rs`）与 `BASE_DELAY_MS`（Python，`online_playback.py`）必须相等，由测试保证。

## 尚未实现

- **命中停顿**：命中瞬间双方动画短暂停止，是强烈的打击感来源。需要能暂停原生动画的钩子，目前没有。
- **按武器的有效帧**：怪物接触窗口仍是固定值，没有按武器单独配置。
- **延迟补偿的怪物攻击**：目前只按固定呈现延迟对齐，没有按每名玩家的实际延迟回溯。
